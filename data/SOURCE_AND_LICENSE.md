# Source and license of the redistributed dataset

## File

`44320_2010_BFMSB201037_MOESM10_ESM.csv`

## Provenance

This file is Supplementary Dataset (Electronic Supplementary Material) accompanying:

> Shimizu, T. S., Tu, Y., and Berg, H. C. (2010). A modular gradient-sensing network
> for chemotaxis in *Escherichia coli* revealed by responses to time-varying stimuli.
> *Molecular Systems Biology* **6**, 382. https://doi.org/10.1038/msb.2010.37

It contains steady-state kinase activity (a, dimensionless) as a function of MeAsp
concentration (mM) upon step stimulation at zero ambient MeAsp, for the fixed-modification
receptor states EEEE, wt, QEEE, QEQE, QEQQ, QQQQ, QEmQQ, QEmQEm and EmEmEmEm.

## Use in this repository

Six fixed-modification states (QEEE, QEQE, QEQQ, QQQQ, QEmQQ, QEmQEm) are used to fit
state-dependent modification free energies under an MWC model, from which the endpoint
calibration derives the methylation free-energy slope alpha, the offset m0, and the
methylation-to-activity susceptibility G_m^A. The file is redistributed unmodified.
