# Reproducibility package

Analysis code and source data accompanying:

> De la Fuente, I. M., Carrasco-Pujante, J., Fedetz, M., Legarreta, L., Malaina, I.,
> Pérez-Yarza, G., Martínez, L., Cortés, J. M., and López, J. I.
> **Quantifying transient biochemical information in *Escherichia coli* chemotaxis.**
> *Biophysical Journal* (submitted).

## Quick start

```bash
git clone https://github.com/JoseCarrascoPujante/ecoli-chemotaxis-information.git
cd ecoli-chemotaxis-information
pip install -r requirements.txt
python chemotaxis_reproducible_analysis.py
```

Runtime is approximately 45 s on a standard laptop (dominated by the 10,000-iteration
bootstrap). All tables, figures and `summary.json` are written to `outputs/`, overwriting
the committed reference copies.

To run the notebook instead, open `chemotaxis_reproducible_analysis.ipynb` in Jupyter and
choose **Run All**. It imports the same module, so the two routes cannot diverge.

## Principal reproduced values

Running the script regenerates, among others:

| Quantity | Value |
|---|---|
| Microscopic capacity `H_micro` | 60,000 bits cell⁻¹ |
| Total-count capacity `H_count` | 15.873 bits cell⁻¹ |
| Free-energy slope `alpha` | 1.99464 |
| Offset `m0` | 0.43654 |
| Susceptibility `G_m^A` | 2.65953 |
| Effective methylation noise `sigma_m` | 0.2550, 0.1523, 0.1365 |
| Mutual information `I(L;m)` | 2.18163 bits |
| Information-equivalent states `N_eff` | 4.5367 |
| Environmental-prior sensitivity | 1.923 to 2.257 bits |
| Environmental timescale `tau_env` | 4.23 to 16.92 min |
| `tau_m / tau_env` | 0.0099 to 0.0394 |
| Corner frequency `f_c` | 0.0159 Hz |
| Boundary-treatment ratios | Supplementary Table S3 |

The script contains a `validate()` function that asserts `alpha`, `m0`, `G_m^A`, `I` and
`N_eff` against the published values and raises an `AssertionError` on mismatch, so a
failed reproduction is reported explicitly rather than passing silently.

## Reproducibility boundary

The package recomputes, from source data and declared model parameters: the capacity
hierarchy, the Shimizu endpoint calibration, the two bootstrap uncertainty layers, the
FRET-to-methylation noise mapping, the static mutual information, the environmental-prior
sensitivity, run-scale ligand changes, the timescale hierarchy, the kinase benchmark, and
the boundary-treatment ratios.

Two quantities are **not** regenerated from raw inputs and are carried as frozen
manuscript outputs, declared explicitly in the script:

1. **Final open-domain dynamic methylation information rates** and their Monte Carlo
   intervals (1.74e-4, 6.67e-4, 1.42e-3, 2.40e-3 bits s⁻¹). Independent regeneration
   requires the original trajectory and spectrum simulation implementation, or the raw
   trajectory data, neither of which is embedded here.
2. **Historical pre-final-calibration boundary rates**, used only to form the
   dimensionless ratios in Supplementary Table S3. Those ratios are calibration
   independent under a common multiplicative recalibration in the weak-SNR regime.

These are labelled rather than reconstructed by an unsupported surrogate model.

## Tested environment

The pipeline reproduces every reported value under:

| Package | Version |
|---|---|
| Python | 3.13 |
| numpy | 2.2.6 |
| pandas | 2.3.3 |
| scipy | 1.15.3 |
| matplotlib | 3.10.9 |

Random number generation is seeded (`seed=20260915`), so the bootstrap is deterministic.
Bootstrap percentiles may differ in the last one or two significant digits across NumPy
versions; no reported quantity is affected at its stated precision.
